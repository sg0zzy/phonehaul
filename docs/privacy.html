Summary

  • PhoneHaul moves files you select from your phone to a computer you pair with, over your local network only. It has no accounts, no cloud service, and no Internet relay.
  • The app does not read data silently: it only processes the files you pick, plus the metadata needed to transfer and verify them.
  • Nothing is sent to any server or third party. The only network destination is the paired computer's private LAN address.
  • The app stores no user data on the phone beyond one app preference. It contains no analytics, advertising, or crash-reporting code.
  • Transfers are encrypted in transit with TLS and a certificate fingerprint pinned from the QR code; cleartext traffic is disabled.

3. Who receives your data

The only recipient is the computer you pair with, running the PhoneHaul receiver or desktop app. The app connects to no other host: the pairing address must be a private IPv4 LAN address, and there is no code path that contacts any third-party server, store, or analytics endpoint. No data is shared with, sold to, or transferred to any third party.

4. How data is handled and protected

  • Encryption in transit. All transfer traffic uses HTTPS. The receiver's certificate is self-signed and ephemeral, so the app pins its SHA-256 fingerprint from the QR code and refuses any connection whose certificate does not match. Cleartext traffic is disabled in the app configuration.
  • Restricted destination. The app rejects pairing codes that point to non-private or link-local addresses.
  • Short-lived credentials. The pairing token is random, expires after five minutes, and is never written to disk on the phone.
  • No logging. The app writes no logs of file names, paths, tokens, or transfer contents. The receiver prints activity to its own local console and does not log session tokens, keys, or certificate material.
  • Verification before deletion. In MOVE mode a source file is deleted only after the receiver confirms the received copy matches in size and SHA-256.
  • No backup. The app is excluded from Android backup (allowBackup="false").

5. Retention

Phone — memory Selection lists, media listings, pairing data, transfer state. Until you disconnect or close the app. Nothing is cached to disk.

6. Deletion

PhoneHaul has no accounts, so there is no account to delete. You control deletion directly:

  • Delete your files on the phone and on the computer at any time.
  • Clear the app's stored preference: system Settings → Apps → PhoneHaul → Storage → Clear data, or uninstall the app.
  • Remove transferred files from the destination folder on the computer, and clean up any leftover partial files.

If you want confirmation that no other copy of your data exists, the answer is that the app keeps no server-side or hidden copies: everything it holds is either in memory or in the files you can see and delete yourself.

7. Third-party dependencies

The app uses only open-source libraries for its user interface, camera, QR decoding, and file access: Jetpack Compose, androidx activity, lifecycle, documentfile, CameraX, ZXing, and JUnit for tests. None of them collect data, perform analytics, show advertising, report crashes, or open network connections. There is no analytics, telemetry, advertising, or crash-reporting SDK in the app.
